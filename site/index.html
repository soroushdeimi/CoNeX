CoNeX

CoNeX is a Python framework for building, simulating, and experimenting with spiking neural networks, with a focus on modeling cortical structures. Built on PyTorch and Pymonntorch, it provides a high-level API to design network architectures inspired by the neocortex, such as cortical layers and columns.

It is designed for researchers and developers in computational neuroscience to create intricate models, define custom neuronal behaviors, and apply learning rules such as Spike-Timing Dependent Plasticity (STDP).

A short, real example

The example below is the HTM sequence-learning script that ships with the library (Example/numenta/htm_sequence_learning.py). Symbols are encoded as sparse distributed representations (SDRs), a Spatial Pooler turns them into a stable set of active columns, and Temporal Memory learns which element follows which. The anomaly score starts at 1.0 (nothing is predicted yet) and falls to 0 once the sequence A B C D is learned; an unexpected symbol (X) spikes it back up. 

import torch
from pymonntorch import Network, NeuronGroup
from conex import (
    SDR, SpatialPooler, SpatialPoolerConfig,
    TemporalMemory, TemporalMemoryConfig, TimeResolution,
)

net = Network(behavior={1: TimeResolution(dt=1.0)},
              dtype=torch.float32, device="cpu")
# ... build a SpatialPooler and TemporalMemory, then:
net.initialize()
net.simulate_iterations(12 * 4)   # 12 epochs of the A B C D sequence

Run it with python Example/numenta/htm_sequence_learning.py. The output we got (CoNeX 0.1.5, Python 3.15): 

epoch  mean anomaly  bursting columns
    0         1.000              10.0
    4         0.275               2.8
    7         0.000               0.0
   11         0.000               0.0

Now break the pattern: A B X D
symbol  anomaly  bursting columns
     A    0.000                 0
     X    1.000                10
     D    1.000                10

Core concepts

A CoNeX model is built from a small set of nested structures. The Neocortex is the top-level network; it holds CorticalColumns, each of which groups Layers (e.g. a cortical layer with excitatory and inhibitory populations). Layers hold NeuronGroups, and SynapseGroups connect neuron groups to each other. Behaviors are the classes that give a group its dynamics (for example an LIF neuron model or an STDP learning rule).
